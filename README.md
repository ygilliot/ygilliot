# Yann Gilliot

Fondateur de [GiLabs](https://gilabs.fr/fr/), cabinet de conseil IA pour PME et ETI, basé près de Nice.

J'aide les PME, ETI et cabinets à réussir leur transformation IA : cartographie des process, roadmap chiffrée, puis développement des agents et des applications qui tournent en production, branchés sur votre existant (Microsoft 365, SQL Server, vos applis métier).

## Ce que je construis

- **Agents IA et automatisation de process** : documents entrants lus automatiquement, process exécutés de bout en bout, validation humaine sur les décisions sensibles.
- **Intégration IA dans des applications .NET existantes** : RAG sur les données SQL Server, agents Semantic Kernel et Microsoft Agent Framework, dans le code et les règles métier en place.
- **Extraction documentaire en production** : Azure Document Intelligence, Mistral OCR, Docling, derrière une interface interchangeable.
